# 样本数据格式

本目录存放决策样本：`state + questions + 标注答案`。
大数据文件不入库（`.gitignore` 已忽略 `*.jsonl`），示例用 `.jsonl.example` 后缀。

## 文件命名

| 文件 | 用途 |
|---|---|
| `train.jsonl` | 训练数据（Phase 4 QLoRA 用） |
| `test.jsonl` | 带标注的测试集（Phase 3 评测用） |
| `demo.jsonl` | 冒烟测试用的少量样本 |

## 单行格式

```json
{
  "id": "sample-001",
  "state": {
    "title": "订单一直没发货",
    "body": "下单三天了还在处理中，能退款吗？"
  },
  "questions": [
    {"id": "q1", "type": "noul", "prompt": "该工单在请求退款吗？"},
    {"id": "q2", "type": "choice", "prompt": "应路由到哪个队列？",
     "options": ["物流", "退款", "技术支持", "其他"]},
    {"id": "q3", "type": "score", "prompt": "该工单的紧急程度",
     "levels": ["低", "中", "高", "紧急"]}
  ],
  "labels": {
    "q1": true,
    "q2": "退款",
    "q3": "高"
  }
}
```

## 标签字段约定

| 原语 | `labels[question_id]` 类型 | 含义 |
|---|---|---|
| `noul` | `bool` | 命题真值 |
| `choice` | `str` | 正确选项，**必须在 `options` 内** |
| `score` | `str` | 正确等级，**必须在 `levels` 内** |

## 标注注意事项

1. **选项设计是关键**。正确答案若不在候选集里，模型的概率仍被迫落在剩余选项上。
   标注前先确认候选集是否覆盖真实类别。
2. **边界样本单独标记**。可加可选字段 `"ambiguous": true`，评测时单独统计，
   避免模糊样本污染校准指标。
3. **每类建议 ≥50 条**才能做有意义的 ECE 分桶统计；正式评测建议 ≥200 条/原语。
4. `state` 可以是纯字符串，也可以是文本字段构成的对象（见 `src/jev_qwen/engine.py` 的
   `format_state`，需保证字段拼接顺序稳定）。

## 数据规模建议（roadmap Phase 2–4）

| 阶段 | 规模 | 用途 |
|---|---|---|
| 冒烟 | 10 条 | 跑通流程 |
| 基线评测 | 每原语 ≥200 条 | 准确率 / ECE / 延迟 |
| 温度缩放拟合 | 验证集 ≥300 条 | 校准 |
| QLoRA 训练 | ≥2000 条 | 微调 |
